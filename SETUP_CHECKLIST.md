# BloodLink setup checklist

- [ ] MongoDB Atlas M0 cluster and `MONGODB_URI`
- [ ] Cloudinary cloud name, API key, and API secret
- [ ] Resend API key and verified sending domain
- [ ] Firebase project, service-account JSON, and Google web client ID
- [ ] Agora project app ID and certificate
- [ ] Render service and custom API domains
- [ ] UptimeRobot monitors for `/healthz` and scheduled jobs
- [ ] GitHub repository for APK releases
- [ ] Production secrets generated and stored in the deployment secret manager
